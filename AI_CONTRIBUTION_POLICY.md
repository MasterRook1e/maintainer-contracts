# AI-assisted contributions

AI tools may assist implementation, tests, policy examples, and documentation, but the human contributor is accountable for every submitted change.

Substantial AI assistance must be disclosed in the pull request with the tools used, affected areas, human review, and validation. Contributors must confirm that no credentials, private repository content, customer data, or incompatible third-party material was supplied to the model or copied into this project.

Generated evidence, fabricated test results, invented users, and unreviewed bulk output are not accepted. AI-assisted changes receive the same correctness, security, licensing, and compatibility review as manually written changes.
