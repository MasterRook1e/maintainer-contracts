# Roadmap

- reusable named policy profiles
- rule suppressions with owner, reason, and expiry
- changed-line-aware path rules
- optional JSON Schema validation through generated standalone code

## 0.3

- signed policy provenance for regulated environments

Priority will follow real maintainer feedback rather than adding arbitrary governance checks.
