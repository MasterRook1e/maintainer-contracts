# Maintainer Contracts v0.1.1

This maintenance release closes a correctness gap in the public repository and strengthens GitHub integration without adding runtime dependencies.

## Highlights

- authenticated GitHub API acquisition for complete pull-request file and commit evidence
- bounded pagination and per-request timeouts
- changed-file count validation against the pull-request event
- fail-closed behavior when evidence is partial or inconsistent
- token-safe errors that omit remote response bodies
- trusted-base workflow guidance for fork-safe policy evaluation
- 17 focused tests plus clean packed-package consumer validation

## Cleanup

- removed an unreachable duplicate evaluator whose omitted test exposed incompatible APIs
- removed duplicate issue forms and a temporary upload probe
- removed a redundant workflow that used an invalid action input

## Verification

The release gate runs linting, the complete test suite, a deterministic smoke test, npm package allowlist validation, and installation/import/execution from the exact generated tarball.
