# Maintainer Contracts v0.1.0

The first public GitHub release of the dependency-free, path-aware pull-request policy engine.

## Highlights

- Markdown section and checklist parsing that ignores fenced code and HTML comments
- required sections, meaningful-content thresholds, checked evidence, and placeholder detection
- path-aware section, label, pattern, and checklist requirements
- pull-request title, review-size, linked-pattern, and independent commit-subject rules
- GitHub pull-request event normalization and shell-free local Git evidence collection
- deterministic console, JSON, Markdown, and escaped workflow-annotation reports
- CLI, library API, and composite GitHub Action
- Node.js 20/22 verification across Linux, Windows, and macOS

## Release evidence

The release workflow re-runs the complete verification gate, packs the exact npm tarball, validates it through the clean packed-consumer test, records SHA-256 checksums, generates a GitHub/Sigstore build-provenance attestation, and uploads those artifacts with the release.

The tag and release target the exact `main` commit that passed this gate; no prebuilt package from another commit is reused.

The action is also publicly dogfooded against real pull-request events in this repository, MiniApp PackGuard, and UE5 Flick Physics. These integrations are maintained by the same GitHub owner and are not represented as independent external adoption.

## Scope and status

This release contains no production pull-request event, tenant model, licensing workflow, authentication system, database schema, credential, proprietary source, or private Git history. It is a GitHub release and installable npm-format tarball; it does not claim that the package has been published to the npm registry or adopted independently.

See `docs/ADOPTION.md` and `docs/THREAT_MODEL.md` for the evidence and security boundaries.
