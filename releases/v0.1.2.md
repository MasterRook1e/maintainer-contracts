# Maintainer Contracts v0.1.2

This patch release fixes a composite-action manifest error discovered by exercising the action from a separate public repository.

## Fix

The `token` input description previously contained GitHub expression syntax. GitHub evaluates top-level action metadata before a job starts and rejected that expression, so the composite action could not be loaded.

The description is now static. Callers continue to pass a read-only token explicitly, and the action forwards it through the environment only.

## Regression coverage

A dedicated action-manifest test now rejects expression syntax in the top-level metadata section and verifies that the token input has an empty default and is forwarded from `inputs.token`.

## Verification

The release gate runs syntax and formatting checks, 19 focused tests, deterministic fixture evaluation, npm package allowlist validation, and installation/import/execution from the exact generated tarball.
